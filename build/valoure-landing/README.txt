VALOURE SLEEP — PRODUCT LANDING TEMPLATE
========================================

What's in this zip:
  templates/product.valoure-landing.liquid   <- the new product page

IMPORTANT: Shopify can't import a single loose file from the admin screen.
The safe, beginner-friendly way is to COPY-PASTE it into your theme's code
editor. It takes about 2 minutes. Here's exactly how.

--------------------------------------------------
STEP 1 — Open the file
--------------------------------------------------
Unzip this folder, then open
  templates/product.valoure-landing.liquid
in any text editor (Notepad, TextEdit, VS Code...).
Select ALL the text (Ctrl+A / Cmd+A) and copy it (Ctrl+C / Cmd+C).

--------------------------------------------------
STEP 2 — Work on a DRAFT theme (never the live one)
--------------------------------------------------
Shopify admin > Online Store > Themes.
Find the theme you want to edit. Do NOT use the live one directly —
click "..." > Duplicate first, and edit the copy. (We also already made
a draft copy for you earlier.)

--------------------------------------------------
STEP 3 — Add the template
--------------------------------------------------
On that draft theme click  "..."  >  Edit code.
In the left sidebar find "Templates" > "Add a new template".
  - Template for:  product
  - Type:          liquid
  - Name:          valoure-landing
Click "Create template". A file called
  templates/product.valoure-landing.liquid
opens. Delete whatever's in it, PASTE your copied code, and Save.

--------------------------------------------------
STEP 4 — Point your product at the new template
--------------------------------------------------
Shopify admin > Products > Weighted Sleep Mask.
On the right, find the "Theme template" box (under "Online store").
Choose  "valoure-landing"  and Save.

--------------------------------------------------
STEP 5 — Preview
--------------------------------------------------
Back in Themes, on the draft theme click "..." > Preview to see it.
Nothing goes live until YOU click Publish.
